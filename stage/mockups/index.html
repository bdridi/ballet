La Scène · trois propositions multi-pages

Maquettes cliquables, style neutre (le design system viendra après). Données réelles d'antimurphy (FEAT-001 à FEAT-005, le Workshop « consume-a-stock-item ») ; FEAT-006.2, TASK-004 et le Workshop BUG-002 sont simulés en direct pour montrer une soirée vivante, avec deux Rehearsals en parallèle.

A · RégieLa v1 qui grandit La sidebar de la v1 reste le centre : En scène, Director attendu, Programme, Features. Une page par objet à droite, une barre d'onglets en haut.

Ce qui la distingue

  • « En scène » : une carte par session, avec son diagramme compact
  • Rehearsal : diagramme + métriques + slices de la feature + fil v1
  • Feature : un Gantt Workshop → Plan → slices
  • Page Distribution : comparer les modèles par rôle

Pour qui

Le moins de risque : on garde les réflexes de la v1.Ouvrir A → B · PlateauLa chaîne est la navigation En haut, la chaîne Backlog → Workshop → Programme → Rehearsal → Premieres avec ses compteurs. L'accueil pose chaque élément sur un grand plateau ; la sidebar change selon l'étape.

Ce qui la distingue

  • Rehearsal sous-découpée en couloirs Plan / Dancer / Script / Critic
  • Diagramme cliquable : un nœud filtre le fil
  • Rejouer une Rehearsal : un curseur dans le temps anime le diagramme
  • Programme en kanban par Ballet status (le champ GitHub)

Le temps se lit comme une partition : une portée par rôle, une mesure par Rehearsal, un ◆ par Premiere. Un lecteur « en scène » reste en bas de chaque page.

  • « Ce soir » : toutes les sessions sur un même axe (le parallèle se voit)

  • Programme : une affiche estimée (quand chaque élément passera)

Ce que les trois couvrent

WorkshopA : page + diagramme + décisions · B : diagramme rejouable · C : conversation + décisions à valider
Rehearsaldiagramme d'états (agents en pilule, étapes du script en rectangle pointillé, Director en losange, nœud courant qui pulse, boucles de retour comptées) + fil v1 (Tout / Échanges / Script)
ProgrammeA : tableau avec démarrage estimé · B : kanban par Ballet status · C : affiche en Gantt prévisionnel ; partout : proposé à accepter et Next up du backlog
En coursA : cartes « En scène » · B : plateau + couloirs · C : lecteur en bas + « Ce soir »
Featuresliste avec stats (slices, durée, allers-retours, lignes, agents / script) et page détail qui liste toutes les slices
Directorune boîte « pour le Director » : escalades, issues proposées (et plus tard, les plans à valider)

Ce que les maquettes ont révélé

  • Le Workshop assisted ne laisse pas de journal : la Scène ne peut montrer que son issue.
  • Les statistiques agent / script viennent des paires handoff → message et proof/mutation start → end : le journal suffit, sans nouveaux événements.
  • Un événement porte désormais rehearsal ou workshop : la page doit lire les deux clés.
  • L'estimation du programme demande une durée médiane par type d'élément, calculable depuis le journal.
